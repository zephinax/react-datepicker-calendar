    Engineered for developer experience.

    Everything you need to ship world-class date pickers with zero configuration headaches.

    React 19 & RSC Ready

    Built-in "use client" banners, forwardRef support, and isomorphic layout effects ensure seamless Next.js App Router and Server Component integration.

    Dual Calendar Systems

    First-class Gregorian and Persian (Jalali) engines built-in with proper month lengths, RTL direction, Persian numerals, and weekend highlighting.

    3 Selection Modes

    Easily toggle between single date, range selection with starting/ending boundaries, or multiple individual date selections with identical prop signatures.

    Accessible by Default

    Complete keyboard navigation: arrow keys for day hopping, Enter for selection, Escape to close, and full ARIA grid and role semantics for screen readers.

    Strict Guardrails

    Set minimum and maximum selectable bounds, specify disabled date arrays, and handle invalid date picks smoothly via onDisabledDayError callbacks.

    Adaptive Theme Support

    Natively matches your application's theme across light and dark modes with CSS variable inheritance, backdrop blurs, and instant custom accent styling.
